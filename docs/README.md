# BetweenGreen 專案文件

整理日期：2026-10-16。

本目錄供 Git 與 current 保存現有功能、已採用的 UIUX 規則與可重複執行的測試方式。以功能為單位維護，不按每次補丁累積版本文件。

| 文件 | 用途 |
|---|---|
| [前台功能與資料規則](guides/FRONT-FEATURES.md) | 已建立的頁面、導覽、精選商品與文章展示規則 |
| [版面與互動規範](specs/FRONT-LAYOUT-INTERACTION-RULES.md) | Header、Hero、內容留白、RWD、命名與樣式慣例 |
| [版面實作說明](guides/FRONT-LAYOUT.md) | Header 共用 token、透明修正、溢出修正與 Hero 定位責任 |
| [Toast 使用與實作](guides/TOAST.md) | 四種狀態、霧白材質、生命週期、5／7 秒與預覽工具 |
| [UIUX 測試規範](guides/UIUX-TESTING.md) | 尺寸矩陣、頁面流程、鍵盤操作、計時回歸與結果記錄方式 |

進度排程、未完成目標、工作對話交接及逐版交付歷史不屬於此文件集。文件描述現有實作與驗證方法，不代表所有頁面、正式資料與裝置都已完成驗收。

規則或程式變更時更新對應功能文件；測試執行結果應記錄當次版本、環境與範圍，不能以文件存在或單一測試通過代替全部驗證。
