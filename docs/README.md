# BetweenGreen 專案文件

本目錄保存現行功能、已採用的規範與可重複執行的測試方法。以功能為單位更新，不按每次交付追加版本指南。

| 文件 | 用途 |
|---|---|
| [前台功能目標與現行實作](guides/FRONT-FEATURES.md) | 功能目標、已完成行為與資料規則 |
| [版面與互動規範](specs/FRONT-LAYOUT-INTERACTION-RULES.md) | 跨頁導覽、Hero、留白、RWD 與樣式慣例 |
| [版面實作](guides/FRONT-LAYOUT.md) | 元件責任、共用 token 與版面技術說明 |
| [Toast 使用與實作](guides/TOAST.md) | 通知狀態、生命週期與開發預覽 |
| [UIUX 測試方法](guides/UIUX-TESTING.md) | 環境、操作步驟、通過條件與測試指令 |

私人目標、方案討論、逐次驗收結果、補充驗收備忘、排程與工作交接不放在此文件集；這類工作資料保存在 Git 忽略的私人目錄。

功能或目標改變時更新對應章節；測試方法改變時更新步驟與條件。文件描述現行實作，不是全站、正式資料或所有裝置的通過證明。Toast 測試腳本隨程式保留版本控制。
